## Key Guidance

### 1. Real Seismic Trace Identification
- Real amplitudes from Zarr (replace random generation)
- Correct axes/units (TWT 0–1996 ms, not 4000; crossline 1900–2099, not fake)
- Amplitude scaling from data stats (p01/p99 clip, not absolute extrema)
- Variable-density colormap + optional wiggle traces
- Proper axis labeling and colorbar

### 2. Fault Overlay Credibility
- Use real model output (UNet), not hardcoded mask
- Display probability (0–1), not binary — allows threshold exploration
- Overlay fault sticks for model-vs-interpretation comparison
- Distinct visual treatment (UNet warm overlay + stick discrete markers)
- Disclose artifacts (edge effects, bright-spot false-positives)
