## Bugs Fixed

### Bug 1 (CRITICAL) — Event Loop Block

**File:** `src/deepseismic/storage/blob_client.py`  
**Method:** `ABSZarrV3Store.get()`  
**Location:** Line ~XXX

**Before:**
```python
raw: bytes = await asyncio.to_thread(blob_client.download_blob().readall)
```

**After:**
```python
raw: bytes = await asyncio.to_thread(lambda: blob_client.download_blob().readall())
```

**Why:** `blob_client.download_blob()` is a blocking Azure SDK call. The original code evaluates it on the main event-loop thread before `to_thread` executes, serializing all concurrent chunk reads. The lambda defers the entire call stack to the thread pool.

### Bug 2 (HIGH) — SuffixByteRequest(0) Edge Case

**File:** `src/deepseismic/storage/blob_client.py`  
**Method:** `_apply_byte_range()`  
**Location:** Line ~XXX

**Before:**
```python
if isinstance(byte_range, SuffixByteRequest):
    return data[-byte_range.suffix :]
```

**After:**
```python
if isinstance(byte_range, SuffixByteRequest):
    if byte_range.suffix == 0:
        return b""
    return data[-byte_range.suffix :]
```

**Why:** In Python, `-0 == 0`, so `data[-0:]` equals `data[0:]` — the full blob. Callers requesting an empty suffix tail would receive the entire blob, corrupting zarr's partial-read contract.

**Regression Test:** Added `TestApplyByteRange.test_suffix_zero_returns_empty()` in hudson-1's test suite.

---

### Bug 3 (MEDIUM) — `set()` Silently Accepts but Ignores Partial Writes

**File:** `src/deepseismic/storage/blob_client.py`  
**Method:** `ABSZarrV3Store.set()`  
**Location:** Line ~XXX

**Before:**
```python
async def set(self, key: str, value: Buffer, byte_range: tuple[int, int] | None = None) -> None:
    self._check_writable()
    # ... rest of method, byte_range never referenced
```

**After:**
```python
async def set(self, key: str, value: Buffer, byte_range: tuple[int, int] | None = None) -> None:
    self._check_writable()
    if byte_range is not None:
        raise NotImplementedError("ABSZarrV3Store does not support partial writes")
    # ... rest of method
```

**Why:** The method signature accepts `byte_range` but ignores it. `ABSZarrV3Store` does not implement the `supports_partial_writes` interface, so partial-write requests should be rejected loudly, not silently accepted and ignored.
