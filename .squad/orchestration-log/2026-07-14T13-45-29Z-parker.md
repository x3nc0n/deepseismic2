### v0.8.1 Patch Release (July 14 — post-release catch)

**Crisis:** After shipping v0.8.0 (UI redesign), post-release smoke testing revealed the deployed Gradio UI container would not boot.

**Root Cause:** 
- `pyproject.toml [ui] extra` had `gradio>=4.40.0` (no upper bound)
- `docker/Dockerfile.gradio` had an explicit `RUN pip install ... gradio ...` line that ran *after* `.[ui]` and won the version race
- No lock file → every build resolved PyPI latest, pulling gradio 6.17.3
- Gradio 6 removed `gr.Chatbot(type="messages")` and relocated `Blocks` theme/css → fatal import errors

**Decision:** Pin `<6`, do NOT migrate to gradio 6 now (too large for emergency patch).

**Changes:**
- `pyproject.toml [ui]`: `gradio>=4.40.0` → `gradio>=4.44.0,<6`
- `docker/Dockerfile.gradio`: removed explicit gradio install (rely on `.[ui]` only)

**Verification:** Smoke tested on gradio 5.50.0 (within `<6` range); UI imports clean, 391 tests pass, ruff clean.

**Skill doc created:** `.squad/skills/dockerfile-dep-pinning/SKILL.md` documenting the Dockerfile unpinned-install foot-gun.
