## Project Context

- **Project:** deepseismic2
- **Description:** Proof-of-concept for petroleum seismic data analysis. Modernizing from legacy monolithic apps (with expensive storage like Dell Isilon, Azure Premium Files, Azure NetApp Files) to affordable cloud-native + AI-enabled workflows.
- **Stack:** Python, PyTorch, Azure, LLM APIs (M365 Copilot, GitHub Copilot, Copilot Studio, Microsoft Foundry)
- **Data:** Equinor Volve dataset (https://www.equinor.com/energy/volve-data-sharing)
- **Reference:** microsoft/seismic-deeplearning (UNet, SEResNet, HRNet for seismic interpretation)
