# DeepSeismic2 Glossary

## SEG-Y
A standard seismic data exchange format used as the source-of-truth input for the PoC.

## Zarr
A chunked, cloud-friendly array format used for derived seismic volumes and intermediate products.

## UNet
A convolutional neural network architecture used here as the first credible baseline for interpretation tasks.

## ADLS Gen2
Azure Data Lake Storage Gen2, used as the object-storage-first system of record.

## Foundry Agent
The AI-native analyst experience that will use tools plus Azure AI Search grounding to help users explore datasets, runs, and results.
