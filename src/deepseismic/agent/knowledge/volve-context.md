# Volve Dataset Context

The Equinor Volve field dataset is the reference dataset for this proof of concept. It provides a public, realistic seismic context for validating ingest, preprocessing, model execution, and analyst-facing retrieval experiences.

For this project, the Volve dataset is used to:
- validate SEG-Y ingest and metadata extraction flows
- test derived storage patterns such as Zarr conversion
- anchor the first end-to-end interpretation workflow
- provide realistic examples for geophysics, geology, and geoengineering grounding materials
